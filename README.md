# Loon 插件合集（loon-plugins）

> 自用 Loon 插件仓库。所有插件均为**纯本地规则、零远程脚本**，安全可控、可审计。

|----------|------|------|----------|------|----------|
| `jd_splash_ad_block.plugin` | 京东开屏广告拦截 | 拦截京东 / 京东金融 / 京东极速版 / 京东云路由 App 的开屏与启动广告 | https://raw.githubusercontent.com/Thelongdarkorg/loon-plugins/main/jd_splash_ad_block.plugin | 需开启 MITM 并信任证书 | `functionId=start` 规则可能使京东“比价”功能失效，不需要可删该行 |

## 🛠 安装方法（通用）

1. **开 MITM**（按需，不是每个插件都要）：Loon → 设置 → 中间件(MITM) → 开启；再到 iOS「设置 → 通用 → 关于本机 → 证书信任设置」手动信任 Loon 证书。
2. **加插件**：Loon → 配置 → 插件 → 右上角 `+` → 选「URL」→ 粘贴对应插件的安装 URL → 安装并开启。
3. **更新**：仓库 push 后，Loon 按 GitHub raw 缓存（约 5 分钟）自动更新；也可手动点「更新」或重启 Loon 强制刷新。

## ➕ 新增插件规范

往本仓库加新插件时，请遵守：

- 文件名用 `英文名.plugin`，便于 URL 引用。
- 文件头部必须包含：
  - `#!name=` 中文名
  - `#!desc=` 一句话中文说明（用途 + 依赖）
  - `#!author=`
- 正文每条规则上方加 `#` 中文注释，说明拦的是什么。
- **不要使用 `script-path=` 指向远程脚本**（避免供应链风险）；需要脚本时务必内联或使用你自己的可信源。
- 在本 README 的「插件列表」里补一行。

## 🔒 安全说明

- 本仓库插件均为纯本地 `reject` 规则，不拉取任何远程脚本、不联网上报。
- 安装 URL 请确保来自本仓库；不要订阅来源不明的远程脚本（尤其是带 `script-path=` 的）。
- 仓库为公开仓库，注意不要在插件里写入个人隐私信息。
